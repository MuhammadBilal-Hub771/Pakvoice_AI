### Which standee to use?

- **Marketing (`standee-5x2`):** Sparse, brand-forward poster when you want maximum impact from a distance.
- **Informational (`standee-info-flow-5x2`):** Denser FYP exhibition board that explains the project, key capabilities, user flow (Login → … → Admin), and architecture (User → Next.js → FastAPI → OpenAI / ChromaDB). Prefer the **HTML layout** view when printing PDF so flow labels stay sharp.

### How to print

1. **Print shop (recommended):** Give them the matching PNG under `assets/` and ask for a **2 ft × 5 ft** roll-up / standee. Confirm **portrait** orientation and do not crop the brand name.
2. **From HTML:** Open `standee-5x2.html` or `standee-info-flow-5x2.html` → **Print / Save PDF**. Set paper/custom size to **24 in × 60 in** (2 ft × 5 ft) if available. For the informational standee, leave **HTML layout** selected for crisp text.
3. Do not flatten to a single color background at the shop — the navy atmospheric design is intentional.
